# Monitor notes

The validator opens `index.html` from the file system in headless Chromium and uses `window.game` for the rules checks, so it does not depend on how the page looks. It also presses the arrow keys and reads the page text to check that the display follows the game.

A person should open the page and judge how it plays and looks: readable tiles, clear colours, a layout that fits a normal window, and a restart control that is easy to find. Record that judgement in the quality score, not in the completion score.
